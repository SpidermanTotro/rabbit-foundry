# v0.4 — Objective coding episodes

Rabbit Foundry now defines three curriculum skills:

1. **code_prediction** — self-supervised continuation from pinned source.
2. **code_repair** — deterministic damage is applied to real source and Rabbit must reconstruct the untouched version.
3. **hidden_diff** — an earlier revision is input and the later pinned revision is the target.

No teacher LLM generates the answer for these tasks.

## Adaptive resampling

Outcomes are recorded by skill. Failed skills gain sampling weight; successful
skills cool toward baseline. Frozen validation/test sources are not resampled
into training.

## Important boundary

v0.4 defines task construction and objective scoring. It does not yet claim that
the tiny byte LM can generate full-file repairs well. The next controller work
must benchmark fixed sampling versus adaptive sampling under the same compute
budget. That comparison is the experiment, not an assumed improvement.
